# YouTrack

> Public entry points for this YouTrack instance that are useful for LLM-based tools and assistants.

Version: `2026.2`

This file points to stable, instance-local resources. Always respect project visibility, issue visibility, and user permissions. If a page or API response is not available to the guest user, it should not be treated as public context for this instance.

## Public Pages

- [Issues](https://youtrack.flowpay.it/issues): Public issue search and list pages. Individual issue pages are available under `/issues/<ISSUE_ID>` and `/projects/<PROJECT_ID>/issues/<ISSUE_ID>`.
- [Articles](https://youtrack.flowpay.it/articles): Public knowledge base article index. Individual article pages are typically under `/articles/<ARTICLE_ID>` or `/projects/<PROJECT_ID>/articles/<ARTICLE_ID>`.
- [Projects](https://youtrack.flowpay.it/projects): Public project list page. Individual project pages are available under `/projects/<PROJECT_KEY>`.

## Structured Data

- [REST API root](https://youtrack.flowpay.it/api): Main REST API entry point for this instance.
- [OpenAPI schema](https://youtrack.flowpay.it/openapi.json): Machine-readable API documentation for the running instance.
- [Hub](https://youtrack.flowpay.it/hub): Authentication and user directory for this instance.
- [Sitemap](https://youtrack.flowpay.it/sitemap.xml): Publicly discoverable pages for this instance.
